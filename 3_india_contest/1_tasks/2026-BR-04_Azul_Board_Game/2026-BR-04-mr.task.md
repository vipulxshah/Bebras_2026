लैला बीव्हर एक खेळ खेळते आहे. तिच्याकडे A, B, C आणि D अशा चार प्रकारच्या टाईल्स आहेत आणि 1 आणि 2 क्रमांकाचे दोन बोर्ड आहेत. बोर्ड 2 वर कुठल्या चौकटीत कुठली टाइल ठेवता येईल ते लिहिलेले आहे.

## Answer Explanation

Therefore, the correct answer is (B).

If Laila uses 8 tiles, then she can complete at most 3 rows in Board 1 if she completes the first row and any two other rows.

This allows Laila to complete the following rows and columns in Board 2:
- the first row, by placing a tile of type D;
- the second column, by placing a tile of type A in the second row and a tile of type C in the fourth row;
- the third column, by placing a tile of type A in the third row and a tile of type D in the fourth row.

However, the last two possibilities are mutually exclusive, because only one type of tile can be placed in the fourth row. Therefore, the best outcome in this round is to complete one row and one column on Board 2.

## This is Informatics

This task can be viewed as solving an optimization problem, as we want to maximize the number of completed rows and columns in Board 2. In computer science, an optimization problem is the problem of finding the best solution from all feasible solutions. Usually this involves finding the maximum or minimum value of something such as cost, distance, time, etc.

## This is Computational Thinking

In this task, students use decomposition to separate the problem into smaller parts. First they look at the possible rows in Board 1 that can be completed, and then they use this information to determine the possible solutions for Board 2.

Students also use evaluation to determine whether each possible solution allows Laila to complete the largest possible number of rows and columns in Board 2.
