## Answer Explanation

சரியான பதில் (C).

ரசீதில் உள்ள 11 விலைகளை, அவை எத்தனை முறை வருகின்றன என்பதன் அடிப்படையில் தொகுத்தால், நமக்குக் கிடைப்பது: 10, 10, 10, 10, 40, 40, 40, 30, 30, 20, 50.

“ரூ.10” என்பது ஒவ்வொரு சிவப்பு ஆப்பிளின் விலையாக இருக்க வேண்டும். ஏனெனில், 4 ஆப்பிள்கள் உள்ளன, மேலும் ரூ.10 மட்டுமே 4 அல்லது அதற்கு மேற்பட்ட முறை மீண்டும் வருகிறது.


“ரூ.40” என்பது ஒவ்வொரு பால் பாக்கெட்டின் விலையாக இருக்க வேண்டும். ஏனெனில், நான்கு ரூ.10 விலைகளை நீக்கிய பிறகு, ரூ.40 மட்டுமே மூன்று அல்லது அதற்கு மேற்பட்ட முறை மீண்டும் வருகிறது.

ப்ரோக்கோலி மற்றும் சீஸ் ஆகிய இரண்டின் விலையும் தலா ரூ.30 என்று ஒருவர் கருதலாம். ஆனால், ரொட்டி இரண்டு உள்ளதால், மீதமுள்ள விலைகளில் மீண்டும் வரும் ஒரே விலை ரூ.30 ஆகும். எனவே, ரூ.30 என்பது ஒரு ரொட்டியின் விலையாக இருக்க வேண்டும்.

இறுதியாக, ரூ.20 மற்றும் ரூ.50 ஆகியவை ப்ரோக்கோலி மற்றும் சீஸ் ஆகியவற்றின் விலைகளாக இருக்க வேண்டும். கொடுக்கப்பட்டுள்ள தகவல்களை மட்டும் வைத்து, இவற்றில் எந்த விலை ப்ரோக்கோலிக்கானது, எந்த விலை சீஸுக்கானது என்பதை நம்மால் தீர்மானிக்க முடியாது. ஆனால் அது பரவாயில்லை.

## This is Informatics
This a task which we can apply the following informatics concepts:

This is a **constraint satisfaction** task where a valid solution must satisfy various conditions (constraints). In this task, we are presented with constraints in graphical form: various numbers of items and prices that must be matched with each other. This task is structured in a way (with different prices for different types of item) that there is a unique solution, and a greedy algorithm without backtracking will arrive at this solution. Specifically, there are two breads in the shopping bag, and there are exactly two copies of just one price "Rs.30".

**Sorting**: Besides the proposed inference method, we can also efficiently match two lists. To do this, we can use sorting.

## This is Computational Thinking

**Abstraction**: This task illustrates the concept of building an abstract model: most of the information in the receipt can be ignored, and only the list of prices of the items need to be retained. The item codes do contain some information, but is equivalent information that is in the prices so they can be ignored. Abstraction is not only a way of thinking, but a computer science method used in all cases to reduce information to data.

**Representation**: This task illustrates the concept of representing data in a way that makes solving the task easier: each item can be represented by its price, and the prices are more easily analysed when represented with some form of clustering.

**Decomposition**: Because different types of items have different prices in this task, this task can be decomposed into several subtasks (one for each item type) that can be solved independently (in any order). One can choose to search only for a price that occurs two times to get the correct answer, but it would be more rigorous to also match off each of the other item types with prices (any order is fine; it does not need to be from most frequent to least frequent) to be sure one's answer is correct.
