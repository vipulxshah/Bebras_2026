விதிகளையும் மைதானத்தின் அமைப்பையும் பார்த்தால், 1-ஆம் கட்டத்திற்குக் கடைசியில் மட்டுமே தாவ முடியும் என்பதை அறியலாம். ஏனெனில், அந்தக் கட்டத்திலிருந்து வெளியேற வேண்டுமெனில் வந்த அதே வழியில் மீண்டும் தாவ வேண்டியிருக்கும்; அது விதிப்படி சாத்தியமில்லை.

21-ஆம் கட்டத்திலிருந்து 12 அல்லது 18 ஆகிய இரண்டு கட்டங்களுக்குத் தாவ முடியும். எனவே, பாதையை கண்டுபிடிக்க 1-ஆம் கட்டத்திலிருந்து பின்னோக்கி யோசிப்பது எளிதாக இருக்கும்.

1-ஆம் கட்டத்திற்கு முன் வரக்கூடிய ஒரே கட்டம் 12. எனவே, 12-ஆம் கட்டம் கடைசிக்கு முந்தைய தாவல் ஆகும்.

12-ஆம் கட்டத்திலிருந்து 3 அல்லது 21-ஆம் கட்டத்திற்குத் தாவ முடியும். ஆனால் 21 நமது தொடக்கக் கட்டம் என்பதால், மீண்டும் அங்கே செல்ல முடியாது. எனவே, 12-க்கு முன் வரும் கட்டம் 3.

3-ஆம் கட்டத்திலிருந்து 10 அல்லது 14-ஆம் கட்டத்திற்குத் தாவ முடியும். அங்கிருந்து தொடர்ந்து செல்ல பல வாய்ப்புகள் உள்ளன.

இப்போது மீண்டும் தொடக்கக் கட்டமான 21-ஐப் பார்ப்போம். அங்கிருந்து 12 அல்லது 18-ஆம் கட்டத்திற்குத் தாவலாம். ஆனால் 12 என்பது 1-ஆம் கட்டத்திற்குச் செல்லும் முன் வர வேண்டிய கட்டம் என்பதால், தொடக்கத்தில் 12-ஐத் தேர்வு செய்ய முடியாது.

அதனால், 21-இலிருந்து முதலில் 18-ஆம் கட்டத்திற்குத் தாவ வேண்டும் என்பதை அறியலாம். இங்கிருந்து மற்ற தாவல்களின் வரிசையையும் எளிதாகக் கண்டுபிடிக்கலாம்.

சாத்தியமான பாதைகளைப் புரிந்துகொள்ள மற்றொரு வழி, செல்லக்கூடிய கட்டங்களை ஒன்றோடொன்று இணைத்து ஒரு வரைபடமாக (Graph) அமைப்பது.

ஒவ்வொரு கட்டமும் ஒரு புள்ளியாக (Node) குறிக்கப்படுகிறது. இரண்டு கட்டங்களுக்கு இடையே தாவ முடிந்தால், அவை ஒரு கோட்டால் இணைக்கப்படுகின்றன.

பச்சை நிறக் கோடு சரியான பாதையைக் காட்டுகிறது.

1-ஆம் கட்டத்திற்கு ஒரே ஒரு இணைப்பு மட்டுமே உள்ளது. எனவே, அது கட்டாயமாக பாதையின் தொடக்கமாகவோ அல்லது முடிவாகவோ இருக்க வேண்டும். நாம் சிவப்பு நிறத்தில் குறிக்கப்பட்டுள்ள 21-ஆம் கட்டத்தில் தொடங்குவதால், 1-ஆம் கட்டமே முடிவுப் புள்ளியாக இருக்கும்.

மேலும், 3, 7, 12, 14 மற்றும் 18 ஆகிய கட்டங்களுக்கு மட்டுமே இரண்டுக்கும் மேற்பட்ட இணைப்புகள் இருப்பதைக் காணலாம். எனவே, இந்தக் கட்டங்களில் உள்ள இணைப்புகளில் ஒரு கோடு பயன்படுத்தப்படாமல் இருக்கும்.

## This is Informatics

The Gray code is a special form of coding in which adjacent code words always differ in exactly one position. The difference between two code words is therefore always 1 (also known as the Hamming distance). This property remains constant between all consecutive code words. In addition, the code is cyclic, which means that the last and first code words also differ in only one position.

This property helps to reduce transmission errors, as it prevents incorrect intermediate states from occurring when several positions are changed simultaneously, for example due to signal interference or signal distortion. This is why Gray code is one of the most robust, error-avoiding coding methods.

## This is Computational Thinking

Computational thinking describes thought processes that make complex problems solvable through structured thinking and systematic calculation steps. This azulejo task applies precisely these skills. First, abstraction can be used to disregard the visual design in order to reduce the house wall to simple binary states, where 0 stands for yellow and 1 for blue.

On this basis, algorithmic thinking is used to develop a strategy for filling the gaps in the wall in a targeted manner. The principle of Hamming distance 1 is applied like an algorithm to the missing parts in order to place them in the correct position step by step.
