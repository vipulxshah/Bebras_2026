ଉପରେ ଥିବା ଛବିରେ ଗାଁର ଘର ଓ ରାସ୍ତାଗୁଡ଼ିକର ଏକ ମାନଚିତ୍ର ଦେଖାଯାଇଛି। ଦୁଇଟି ଘର ମଧ୍ୟରେ ଥିବା ପ୍ରତ୍ୟେକ ରାସ୍ତା (କଳା ରେଖା) ଠିକ୍ 1 କିଲୋମିଟର ଲମ୍ବା।

ଆଈ ବଡ଼ (ଲାଲ୍) ଘରେ ![redh] ରୁହନ୍ତି, ଏବଂ ତାଙ୍କ ନାତିନାତୁଣୀମାନେ ଛୋଟ (ହଳଦିଆ) ଘରଗୁଡ଼ିକରେ ![yellowh] ରୁହନ୍ତି। ସବୁଜ ଘରଗୁଡ଼ିକ ![greenh] ହେଉଛି ଖେଳନା ଦୋକାନ ଏବଂ ଧୂସର ଘରଗୁଡ଼ିକରେ ![grwyh] ଅନ୍ୟ ଲୋକମାନେ ରୁହନ୍ତି।

ଆଈ ଖେଳନା ଦୋକାନଗୁଡ଼ିକ ମଧ୍ୟରୁ (ଏକମାତ୍ର) ଗୋଟିଏ ଦୋକାନରୁ ଖେଳନା କିଣି, ତିନୋଟି ହଳଦିଆ ଘରରେ ଥିବା ନିଜ ନାତିନାତୁଣୀମାନଙ୍କୁ ଦେବାକୁ ଚାହୁଁଛନ୍ତି।

## This is Informatics

This task is a good example of how to translate an everyday situation into the language of computer science and solve it using well-known models in computer science. From the point of view of computer science, it is not just about the shortest path between two points, but about planning a route with multiple objectives and constraints that must be satisfied in the correct order. Such problems belong to optimization on graphs with constraints.

Graphs are computer scientist’s way to represent connections between objects – here roads between houses. They are used to model many real life problems, like finding the shortest path between two places on a map.

This task is a little more involved: you cannot simply look for the shortest path that contains Grandma’s house, one shop and the three houses of the grandchildren, because the order in which you visit the places on the map, is very important here: you have to visit a shop first. So, some times computer scientists need to adapt well-known algorithms (find the shortest route) to the specific problem at hand.

## This is Computational Thinking

Decomposition - In this task, we made solving the problem easier by splitting it into separate problems: first to find the shortest route through the three grandchildren’s houses, then adding the fact that grandma needs to get home, and only after that we considered the first part of the journey. Dividing the problem in this way made it easier to solve it correctly.

Algorithmic thinking - The solver has to design a strategy for solving the route-planning problem and then apply it. This may involve comparing possible toy shops, identifying parts of the map that force detours, keeping track of whether the gifts have already been bought, and checking which yellow houses have already been visited.

Evaluation – The solver compares several possible routes and checks which of them satisfies all conditions with the smallest number of travelled roads. It is not enough to find one valid route; the solver must also evaluate whether another route could be shorter. This includes rejecting routes that require unnecessary backtracking.
